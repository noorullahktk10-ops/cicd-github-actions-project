# CI/CD Pipeline with GitHub Actions

Implemented a complete CI/CD pipeline using GitHub Actions for a Python Flask application.

### 🚀 What I Implemented:
- Automated Build & Test Workflow
- Python dependency installation
- Unit testing with Pytest
- Auto trigger on push to main branch

### 🛠️ Tech Stack:
Python, Flask, Pytest, GitHub Actions, YAML

### 📸 Workflow Result:
Workflow runs successfully on every push - see Actions tab ✅

### 🔗 How it Works:
1. Code push to main -> GitHub Actions triggers
2. Sets up Python environment
3. Installs dependencies from requirements.txt
4. Runs tests

Built as part of GitHub Copilot & GitHub Actions learning path.
